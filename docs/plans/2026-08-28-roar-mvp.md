# Roar MVP (粤语正字语音输入) Implementation Plan

> **For agentic workers:** 按本计划任务逐项实施。步骤用 checkbox（`- [ ]`）跟踪。
> 每个任务自足：只读本任务 + Global Constraints 即可完成。

**Goal:** 交付可构建、可安装的 Android 粤语正字语音输入法 MVP——语音识别（sherpa-onnx 端侧）→ 粤语文本正字化 → IME 候选上屏。

**Vision:** 长期规划阶段 S1/3（粤语 MVP，见 VISION.md）。本计划完成 S1。

**Architecture:** 两层转写。ASR（sherpa-onnx）输出粤语文本；core/ 正字引擎（纯 Kotlin）做普化文本→正字候选；IME 展示候选并上屏。详见 `ARCHITECTURE.md`。

**Tech Stack:** Gradle 8.9 / AGP 8.5.2 / Kotlin 2.0.21 / Compose BOM 2024.10.00 / minSdk 26 / targetSdk 35 / JDK 17 / sherpa-onnx Android / Robolectric 4.14.1 / JUnit 4。

**Spec:** `ARCHITECTURE.md`（§3 模块划分、§5 词典格式、§7 验收标准）

```kotlin
// DictEntry.kt
@Serializable
data class DictEntry(
    val hanzi: String,        // 正字，如 "唔該"
    val jyutping: String,     // 数字调粤拼，如 "m4 goi1"
    val freq: Int,            // 词频权重，越大越优先
    val note: String? = null,
)

// DialectDictionary.kt
class DialectDictionary(entries: List<DictEntry>) {
    fun lookupByHanzi(exact: String): List<DictEntry>        // 精确正字反查
    fun lookupByJyutping(jy: String): List<DictEntry>        // 粤拼查正字（空格分词后全匹配）
    fun suggestReplacements(text: String): List<DictEntry>   // 文本中可正字化的词（按最长词优先）
    companion object { fun loadFromJson(json: String): DialectDictionary }
}

// TextNormalizer.kt
object TextNormalizer {
    // 把普化/谐音文本转正字候选；input 为 ASR 输出文本
    fun normalize(input: String, dict: DialectDictionary): List<String>
    // 返回候选列表（第 0 个为最可能），无匹配时返回 [input]
}

// CandidateRanker.kt
data class RankedCandidate(val text: String, val score: Double)
object CandidateRanker {
    // 综合排序：词频 + 上下文 bigram 共现（context 为上一句/上一候选）
    fun rank(candidates: List<String>, dict: DialectDictionary, context: String?): List<RankedCandidate>
}
```

- [ ] **Step 3: 实现 `DictEntry.kt` + `DialectDictionary.kt`**

- `DictEntry`：kotlinx-serialization `@Serializable` data class，字段如上
- `DialectDictionary`：

  - `suggestReplacements`：对输入文本做**最长词优先**匹配——先把词典词按 hanzi 长度降序，逐个 `text.contains(hanzi)` 收集

- 粤拼字段规范化：`jyutping.trim().replace(Regex("\\s+"), " ")`

- [ ] **Step 4: 实现 `TextNormalizer.kt`**

- `normalize(input, dict)`：
  1. `dict.suggestReplacements(input)` 得可替换词表（按词典顺序=词频排序）
  2. 依次替换：用 `hanzi` 精确替换文本中出现的同形词（注意：ASR 输出"无该"时词典含"唔該"但文本是"无该"——**核心难点**：ASR 谐音与正字字形不同，不能靠字形匹配）
  - **实现方案（谐音映射表）**：内置 `COMMON_HOMOPHONE_MAP: Map<String, String>`，把常见普化谐音映射到正字，如 `"无该" to "唔該"`、`"系" to "係"`（仅当"系"作为粤语判断词）、`"嘅"` 直接命中。替换顺序：先整词映射（无该→唔該），再单字映射
  3. 替换结果作为候选 0；原文本作为候选 1（保底）
  4. 返回 `listOf(替换结果, 原文)` 去重
- 同音映射表至少含：无该→唔該、多D→多啲、系→係、系边→喺邊、嘅、呢、乜、冇、唔、睇、嚟、返、傾偈、拍拖、靚仔、大佬、細佬、屋企、聽日、尋日/琴日、食飯、瞓覺、而家、聽講（**只收你确定正确的**）

- [ ] **Step 5: 实现 `CandidateRanker.kt`**

- `rank(candidates, dict, context)`：
  - 对每个候选打分：词典词命中加分（`suggestReplacements(candidate).sumOf { it.freq }`），候选 0 加 1000 基准分（引擎主推）
  - `context` 非空且候选含 context 尾词时额外 +500
  - 按 score 降序返回 `RankedCandidate(text, score)`

```kotlin
// RecognizerListener.kt
interface RecognizerListener {
    fun onPartial(text: String)   // 边说边出（可选）
    fun onFinal(text: String)     // 一句话结束
    fun onError(message: String)
}

// SherpaRecognizer.kt —— 封装 sherpa-onnx OnlineRecognizer
class SherpaRecognizer(
    private val context: Context,
    private val listener: RecognizerListener,
) {
    fun start()          // 开始录音（AudioRecord 16k mono pcm16）+ 识别
    fun stop()           // 停止并 flush，触发 onFinal
    fun release()        // 释放资源
    companion object {
        fun isModelReady(context: Context): Boolean   // assets/模型目录存在且完整
    }
}

// ModelProvider.kt
object ModelProvider {
    fun modelDir(context: Context): File   // context.filesDir/models（或 assets 解包）
    fun ensureModels(context: Context): Boolean  // 从 assets 解包到 filesDir（若 assets 打包）
    fun sha256(file: File): String
}
```
